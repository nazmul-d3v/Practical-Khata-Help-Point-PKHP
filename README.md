## 📖 প্রজেক্ট ওভারভিউ (Project Overview)

**Practical Khata Help Point (PKHP)** হলো একটি আল্ট্রা-মডার্ন ও পূর্ণাঙ্গ ওয়েব অ্যাপ্লিকেশন, যা এসএসসি (SSC) ও এইচএসসি (HSC) বিজ্ঞান বিভাগের শিক্ষার্থীদের প্র্যাকটিক্যাল খাতা সম্পর্কিত সমস্ত ঝামেলা দূর করতে তৈরি। শিক্ষার্থীরা তাদের পছন্দের বিষয় নির্বাচন করে রিয়েল-টাইমে মোট মূল্য হিসাব করতে পারে, খাতার ডেমো ড্রয়িং দেখতে পারে এবং ১-ক্লিকে সরাসরি সুরক্ষিতভাবে অর্ডার কনফার্ম করতে পারে।

## ✨ মূল ফিচারসমূহ (Key Features)

### 🧮 ১. লাইভ প্র্যাকটিক্যাল প্রাইস ক্যালকুলেটর ও কাস্টম বিল্ডার
- **জিরো অটো-অ্যাড (Customer-Controlled):** পেজ লোড হলে স্বয়ংক্রিয়ভাবে কোনো মূল্য যোগ হবে না; শিক্ষার্থী নিজেই নিজের ক্লাস, বিভাগ ও প্রয়োজনীয় বিষয়সমূহ সিলেক্ট করতে পারে।
- **রিয়েল-টাইম হিসাব:** প্রতিটি বিষয়ের মূল্য, সম্ভাব্য ডেলিভারি চার্জ এবং ডিসকাউন্ট সহ মোট খরচ নিমিষেই স্ক্রিনে প্রদর্শিত হয়।
- **কাস্টম বান্ডেল ডিসকাউন্ট:** সম্পূর্ণ কম্বো অর্ডার করলে স্পেশাল ডিসকাউন্ট প্রযোজ্য হয়।

## 🚀 প্রজেক্ট চালু করার নিয়ম (How to Run Locally)

এই প্রজেক্টটি কোনো হেভি ফ্রেমওয়ার্ক নির্ভর নয়, তাই যেকোনো সাধারণ ব্রাউজার ও লোকাল সার্ভারে তাৎক্ষণিকভাবে চলে।

### পদ্ধতি ১: পাইথন লোকাল সার্ভার (Python HTTP Server)
```bash
# প্রজেক্ট ডিরেক্টরিতে যান
cd e:/PKHP

# পোর্ট ৩০০০-এ লোকাল সার্ভার চালান
python -m http.server 3000
```
এরপর ব্রাউজারে প্রবেশ করুন: **`http://localhost:3000`**

### পদ্ধতি ২: Node.js (npx serve / live-server)
```bash
npx serve -l 3000
# অথবা
npx live-server --port=3000
```

### পদ্ধতি ৩: সরাসরি ব্রাউজারে ওপেন
- `index.html` ফাইলটিতে ডাবল-ক্লিক করলেই যেকোনো আধুনিক ব্রাউজারে প্রজেক্টটি চালু হবে।
